I led the product design for the service renewal of Astream, Japan’s first SNS marketing tool leveraging psychographic analysis. The goal was to transform the service into a streamlined platform where users could efficiently identify the best influencers for strategic marketing.

## Overview and hypothesis

Astream manages over 2 million account profiles from platforms like Instagram, YouTube, TikTok, and X. The challenge was to organize this vast amount of data into an intuitive system that helps users discover influencers efficiently.

**Hypothesis**

- Simplified and strategic search pathways would help users navigate large datasets and select optimal influencers.
- Redefining key features and presenting data clearly would enhance user engagement and decision-making.
- Iterative UX improvements would lead to a more seamless and effective user journey.

## Solution

**Redefining Search Priorities**\
I reorganized search priorities and key features to ensure a logical flow that connects users’ actions from influencer search to performance measurement.\
\
**Intuitive UI Design**\
I developed a clear and user-friendly interface that simplified the presentation of complex data, making influencer selection intuitive.\
\
**Iterative UX Testing**\
Through multiple rounds of user testing, I continuously refined the designs to improve the overall experience and ensure the system met user needs effectively.

## Impact and learning

**Impact**

- **Improved Efficiency**: Users could efficiently navigate over 2 million profiles to identify the best influencers.
- **Enhanced User Journey**: A seamless flow from search to performance measurement provided a smoother experience.
- **Strategic Decision-Making**: Clear data presentation enabled users to make informed marketing decisions.
- **Industry Recognition**: In 2024, Astream achieved the highest SaaS NPS in Japan and expanded its influencer marketing services to seven countries across Asia.

**Learning**

- **Clarity in Design**: Presenting complex datasets in an intuitive way significantly improves user engagement.
- **Continuous Testing**: Iterative user testing is essential for achieving an optimal user journey.
- **Focus on User Needs**: Redefining features based on user behaviors ensures the platform aligns with their goals.

This project demonstrated the value of combining data organization with thoughtful design to create a highly efficient marketing tool. Astream’s success reflects its ability to address user needs while achieving measurable impact across the industry.
